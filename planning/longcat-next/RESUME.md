## 面试追问准备

- 为什么保留 replicated embedding？rank-0 depth head 单独访问 TP embedding 可能留下不对称 collective；优化删除第二份 clone。
- 为什么 code 0 必须反馈？它属于真实量化码域；有无帧由控制状态/网格判断。
- 为什么只修小问题？低耦合、可复现、易审核；CFG runtime 需要成对生命周期设计，测试证据不同。
- 为什么 8 级不能全并行？后一层条件依赖前层采样码；跨请求同级 batch 与静态 graph 保留因果关系。
- 为什么 CPU 通过还不够？stub 不覆盖真实 remote-code head、TP collective、权重加载、scheduler 和媒体质量。
- 为什么尚不宣称 Ascend？框架平台支持与具体模型完整 E2E 是不同证据，CUDA 假设仍需处理。
